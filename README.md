# 나라 수도 맞추기

2026 충북 AI 페스티벌 체험 부스용 웹앱입니다. 초등학생이 만든 세계 수도 퀴즈를 업그레이드했습니다.

- `index.html`: 업그레이드한 앱
  - 50개 나라의 사진·국기·힌트를 보고 4개 보기 중 수도 고르기 (10/20/50문제)
  - 힌트 없이 맞히면 100점, 힌트를 보고 맞히면 50점
  - 지어낸 "상위 몇 %" 대신, 오늘 부스에서 도전한 사람들 가운데 진짜 순위 표시
  - 틀린 문제 다시 보기, 틀린 문제만 다시 풀기
  - 국기는 그림 파일로 표시 (Windows에서는 국기 이모지가 글자로 보이기 때문)
- `board.js`: 부스 공용 랭킹 (Firebase Firestore, 컬렉션 `capital`). 다른 부스 앱과 같은 파일입니다.
- `원본_학생작품.html`: 학생이 만든 원본

## 사진에 대하여

원본의 사진 50장을 한 장씩 확인했습니다. 수도가 아닌 다른 도시(보기에 오답으로 나오는 도시)가 찍혔거나 어느 나라인지 확인할 수 없는 14장은 빼고, 국기와 설명이 들어간 그림으로 바꿨습니다. 남긴 36장의 사진 설명은 실제로 사진에 보이는 것만 적었습니다.

- 사진: Unsplash (images.unsplash.com)에서 불러옵니다.
- 국기: flagcdn.com 에서 불러옵니다.
- 인터넷이 안 되면 사진과 국기 대신 색 배경과 국기 이모지가 나옵니다.
